## Replacing a photo
Drop a new file with the same name here (keep `.jpg`). To change which photo a
section uses, edit the `IMAGES` map in [`src/lib/site.ts`](../../src/lib/site.ts).

> Photos were exported to JPEG (~170–270 KB each) and are lazy-loaded except the
> hero. For new photos, ~1600px on the long edge through
> [squoosh.app](https://squoosh.app) keeps the page fast.
